# 下一轮：保真 L1 与高层增补的语义门槛

这是本轮结果支持的后续实现方案，尚未实施。当前两组全量及一次独立复测已完成，不继续根据同一全量分数修改本轮冻结规则。

## 为什么当前方案还不够

本轮首测五层方案净增 5 题，独立复测的 312 道输入改变题净减 4 题。高层扩展的收益与额外上下文干扰处于相近量级。

在固定开发样本的一道邀请活动问题中，正确的“看电影或去公园”事实同时存在于两组证据里，高层增补后却被另一次会话中的冰淇淋信息干扰。这个问题在两次正式比较中均退步。可见“新日期＋词面相似＋来源链接”不是充分的答题相关性门槛。

同时，原 W0 使用原始对话证据，而本批 L1/L2 已由模型改写。索引继承可以防止上层继续丢失子事实，不能恢复 L1 摘要阶段已经丢失的词句和对话指代。

## 1. 把原始引文持久化进 L1

在构建阶段从冻结 Add 数据生成独立批次的 L1 原文单元，保留 `source_id`、`observed_at`、`role`、完整 `original_text`、会话内位置和相邻引文 ID。旧 L1 摘要单独保留为 `abstract`，不能冒充原文。

L2–L5 持久化子事实与原文 ID 的继承关系，高层摘要用于检索导航。查询只读取已经写入 L1 的引文和继承关系，不临时打开外部 L0。报告必须明确这是改变了 L1 存储内容，不得把复制进去的原文伪装成此前摘要系统自身恢复出的信息。

这一步需要一个新的严格 L1/L2 对照，不能把恢复引文带来的单跳提升算成 L3–L5 的贡献。

## 2. 上层的语义路由回到可核验原文

将当前词面导航链接保留为候选，增加事件级约束：主体、谓词/活动、对象、关联人物、完成/计划/否定，以及观察时间与事件时间的区别。新会话时间本身不能作为相关性的加分理由。

高层候选必须定位到子事实及原始引文。只能把定位到的原文窗口加入证据，不能把未经支持的高层推断直接当成事实。含糊链接应回退到底层候选，保留“缺乏支持”的状态。

语义路由或重排器只读取问题和候选记忆，不读取任务类别、金标准、题目 ID 或历史判分。若引入额外模型调用，应给 L1/L2 对照同等的重排/验证计算预算，避免把更多推理调用当成记忆层级增益。

## 3. 验证新增证据是否回答了同一个问题

增补筛选应检查新增内容是否涉及同一个事件或关系，而不是仅共享人物和主题。对日期题保留原时间粒度；对列表、计数及跨会话关系题保留可枚举的来源。

可以探索“底层证据＋高层候选”的支持性核验：要求新增候选提供明确引文，并说明它补充了哪一项所问事实。该说明只用于选择证据，最终答案提示保持统一。没有获得支持时回退原证据，不强塞高层结果。

支持性核验器也需要预算匹配的纯低层对照，不能只对五层方案额外运行一次更强的答题流程。

## 4. 下一次实验冻结方式

建议至少分为：

- 保真 L1＋L2 检索，统一格式和重排预算。
- 同一 L1/L2 事实库＋L3–L5 语义导航，统一格式和重排预算。

先在新的开发会话中调通来源、去重、时间粒度和增补支持性，再冻结规则。现有 40 题已经用于两轮开发，不再作为独立验证。完整报告保留旧 861 题用于历史对比，并补充新的会话或数据验证。

验收时同时检查总体与各类型净变化、配对修复/退步、独立复测方向及额外模型用量。单次略高而复测反向的结果，应保留为研究记录，不宣布稳定优于。
