# 层级导航、继承事实与受控消融

本实验继续使用本地冻结快照和 deepseek-v4.1-flash，不写太忆空间。原 W0 的证据包含原始对话，不能作为“纯 L1/L2”的严格消融组。本批同时建立真正的 L1/L2 检索组与 L1–L5 联合导航组。

## 排查结果

上一轮固定 40 题 smoke 的 15,656 行事实中，有 2,963 行完全重复，每题重复比例中位数约 18.7%。同义改写的重复没有计入。

L1/L2 按对话、观察时间和规范化事实正文合并后，得到 7,157 个事实单元。原节点保持不变，新建独立的规范化索引。某些 L1 时间没有使用方括号；它们的观察时间由对应的单次原始会话分组核验，不能从高层窗口回填。

16,950 个高层摘要单元中，16,884 个达到子事实词面匹配门槛，66 个没有合格链接，不直接作为事实输出。431 个底层事实没有强词面上层链接。这是压缩覆盖的排查线索，不能直接解释为已确认丢失了 431 条语义事实。相似度达到严格门槛的跨日不一致候选为 0，也不代表所有摘要事件日期均已得到语义证明。

## 存储与召回

1. 事实正文来自已有 L1/L2，保留节点来源、单次会话观察时间及经过原文字符区间核验的短时间注释。
2. L2 继承其 L1 子事实；L3、L4、L5 确定性继承全部后代事实 ID，事实不再经过多轮模型改写。原有高层摘要保留用于导航。
3. 高层摘要单元只链接到其实际后代事实。链接分数用于候选导航，不宣称构成语义蕴含证明；实际作答正文始终来自子事实，日期也始终来自子事实。
4. 底层和导航通道均采用 SQLite FTS5（porter unicode61）检索，按对话隔离。所有层级共享同一份事实库。
5. 上层的 L3/L4/L5 路径通过按层级去重的 RRF 融合参与路由。相同事实只呈现一次，重复路径不会重复灌入答案证据。
6. 上下文窗口保留命中事实附近各两条，并在需要时保留同会话开头两条，以保存说话人和语境。窗口不会跨观察时间。

## 开发过程与冻结策略

第一版使用 20 个窗口，保护前 16 个、由上层候选替换末尾最多 4 个。固定 40 题 smoke 中，L1/L2 为 31/40，联合方案为 28/40。退步样例中有正确事实仍在两组证据里的情况，提示额外上下文也可能造成干扰。该版本的请求和结果均保留在带 `_v1_unconditional` 后缀的目录。

第二版在两组中统一使用最多 24 个窗口，联合方案保护前 20 个底层窗口。高层仅对词面启发式识别的组合、列表、计数等候选查询提供增补；直接日期查询保留底层结果。该启发式不保证完整的自然语言意图理解，最终还要求：

- 导航摘要具有查询中的信息词支持，频繁出现的人名等不能单独触发扩展；
- 子事实链接达到门槛；
- 增补中心来自保护窗口尚未覆盖的观察时间；
- 子事实尚未在当前证据中出现。

不满足条件时回退到底层窗口。五层共同参与路由，只有满足条件的高层命中改变作答证据，不强求每题都出现五份摘要。

第二版 smoke 仍用原来的同一 40 题，L1/L2 为 29/40，联合方案为 30/40。该样本属于开发样本，小幅提升不作为有效性的证明。规则、样本和代码哈希在 `preregister_full.json` 中冻结后，再执行两个 861 题全量。全量结果不再用于修改本轮规则，同时报告剔除开发样本后的 821 题。

## 比较的控制条件

- 相同事实库、对话隔离、最多 24 个窗口、上下文规则和 W0 格式化函数。
- 主证据沿用 W0 的 117,760 token 预算，另扣查询；新增时间注释上限 8,000 字符。
- 相同答题模型、判分模型、提示模板与温度 0。
- 构建存储时不读题目或金标准。测试只读规范化事实库和路由索引，不读取 L0。
- 查询路由不使用任务类别、答案、题目 ID 或历史正确性。
- 同一阶段中，完全相同的模型输入按完整提示、角色、模型、温度和端点共享响应，减少相同输入重复调用造成的随机差异。全量不读取开发 smoke 的模型响应缓存，也不读取历史实验答案作为缓存。
- 以全量配对正确/错误变化和双侧精确 McNemar 检验辅助判断，单次得分的微小差异不足以证明稳定优越。

本实验检验的是“高层导航是否改善同一底层事实库的证据选择”，不验证云端原生 TiMEM 召回，也不等价于增加了新的原始事实。

## 复现文件

- `store.json`、`index.sqlite`：实际事实库、继承关系、导航链接及检索索引。
- `storage_audit.json`、`input_audit.json`：来源、继承完整性、重复和对话隔离审计。
- `rules.json`、`preregister_full.json`：冻结的规则与开发记录。
- `requests/lower_only/`、`requests/all_levels/`：每题实际证据、事实 ID 和路由来源。
- `smoke/`、`full/`：各组逐题答案、判分、用量和模型响应缓存。
- `grounded.py`、`evaluate.py`：构建、召回、渲染与断点续跑。
