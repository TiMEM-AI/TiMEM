# R1.1 P1 结论：三种选择器都没有可接受的候选

## 1. 三种选择器，同一结果

| 选择器 | 判定依据 | 结果 |
|---|---|---|
| P0 事务式（token 槽位） | 问题信息词是否已被 B 覆盖 | 80 题中 0 次替换、仅 1 题变化 |
| P1 实体/关系槽位 | 实体、关系、时间/地点/人物类型槽位 | **0 次接受，五组全部等于 B** |
| P1 模型筛选（预算匹配，两臂共享） | 模型逐候选输出 supported/relevance/covers | 已完成 51/80 题：**接受 0**；每题候选仅 6–11 个 |

三组数字一致：**不是选择器判错，而是候选池里几乎没有“B 尚未包含的新事实”。**

## 2. 根因

```text
B  = 用 BM25 取 top-400 事实 → 按命中事实构造原子窗口 → 取 24 个
路由 = 由同一批 L1/L2 事实聚合出的 L3–L5 摘要，target 指回这些事实
```

- 折叠后 6,581 个路由组，目标事实绝大多数已在 B 的前 24 窗口里；
- 剩余可展开的目标（`target not in B`）每题只有 6–11 个，且多为 BM25 尾部噪声；
- 模型筛选把这些候选判为 unrelated/unsupported，接受 0。

**所以高层导航在当前索引结构下没有“新可达事实”。** 这不是选择标准太严，而是
高层节点与其子事实同源——它们描述的是同一批事实，只是粒度更粗。

## 3. 与方案假设的关系

方案 5.1 预期：折叠同源路径后，高层仍能带来“不同层级视角下的补召回”。
实测：**折叠确实消除了重复投票（16,950→6,581），但也把高层能提供的候选压缩到与 B 同源**，
没有产生新的可回答事实。

按方案 7.1 节第 4 条：**“若高层几乎没有有效增补或已知误接受频繁，先报告机制尚未形成，停止扩测。”**
当前正是这个情形，因此：

- **不进入两次全量配对**；
- 不宣布“高层假设失败”，因为尚未测试“不同源”的高层索引；
- P0 的修复（原子窗口、事务式替换、纯删除=0、目标呈现=0 缺失）仍然有效，可作为后续基线。

## 4. 下一步的两个选项

**选项 A（继续 R1，但换索引构造）：**
让 L3–L5 只索引“低层检索未覆盖的事实”，或按事件/关系重新聚合而非按时间窗聚合，
使高层真正可达 B 之外的事实。这需要重建高层索引，属于新的构建批次。

**选项 B（转 R2）：**
按方案第 8 节，把 L1 换成保真原文引文，再做事件级时间绑定与实体对齐。
R2 解决的是“摘要丢失细节”，与本题的“高层同源”是两个独立问题。

我的建议：先做一次**小样本诊断**判断 B 漏掉的事实是否在摘要里已经丢失——
若是，R2 优先；若否，则按选项 A 重建高层索引。
