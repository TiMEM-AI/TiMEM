# 可选原文证据召回

L1摘要可能漏掉对话中的金额、日期或事件。本模块在写入L1后保留消息级原文，在搜索时同时检索原生记忆和原文，帮助答题模型核对摘要遗漏的细节。此功能默认开启，不改变 `/aml/add`、`/aml/search` 或产品接口的请求和响应格式。

## 启用与关闭

默认开启。只需（可选）指定索引路径：

```sh
export TIMEM_SOURCE_EVIDENCE_PATH=data/source_evidence.sqlite
python -m server
```

若要关闭，显式设置后重启服务：

```sh
export TIMEM_SOURCE_EVIDENCE=0
```

开关打开后新写入的消息才会建立原文索引；已有记忆不会自动补录。切到默认开之后，线上旧库仍需重新 Add 才会有原文。
索引与原生记忆分别存储，部署时应一同备份；使用不同数据目录可以隔离环境。

## 流程

- Add成功生成L1后，逐条保存消息、角色、原始时间和用户范围，以L1记忆ID关联来源；相同ID与相同输入可重复写入，不同输入会报错。
- Search在同一user_id内检索原生候选和SQLite FTS5原文候选，用RRF融合；每个原文块选最多3条匹配消息和前后相邻消息。已经召回的原生摘要与原文同时保留，避免短窗口遗漏摘要中的事实。
- 只使用Add消息和Search问题，不读取标准答案。返回数量不超过请求的top_k。

该功能没有启用查询拆分、时间归一化或独立reranker。FTS关键词检索存在漏召回风险，短窗口也可能遗漏未被摘要保留且未命中的事实。原文会扩大输入和存储量；服务端生成成功与原文索引写入分属不同存储步骤，发生写入故障时Add会报告失败，现有上游重试流程可能重新生成L1。请在部署时监控错误并备份索引。

## 验证与实验边界

```sh
python -m pytest tests/test_source_evidence.py tests/test_server_contract.py -q
```

此前本地LongMemEval开发集测试使用独立的实验适配器，58题中原生36题正确、短窗口45题正确；模型答题和判分为本地配置，一题返回400，未计入分数。该结果不能视为此分支生产服务或官方榜单的效果，仍需在目标部署上验证。测试代码使用合成数据，不包含benchmark数据或模型密钥。
